How this dashboard works

Edit any section using the navigation on the left, then click Save Changes at the bottom. The dashboard commits content.json directly to GitHub via the API — GitHub Pages automatically rebuilds your site within a minute or two.

Tip: Your GitHub Personal Access Token is stored only in this browser tab's session memory and is never sent anywhere except GitHub's own API.
